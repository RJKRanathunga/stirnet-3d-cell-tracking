# Default feature manifest

The model contracts deliberately separate **measurements**, **missingness**, and **reliability**. A missing error must never look like an error of zero.

## Tracklet observation stream: 48 channels

Each of the 24 primitives below is paired with one validity bit, producing 48 channels per observation:

```text
relative_position_z/y/x_um

global_shift_z/y/x_um
velocity_z/y/x_um_per_frame
relative_velocity_z/y/x_um_per_frame
acceleration_z/y/x_um_per_frame2

log_volume
delta_log_volume
axis_major / axis_middle / axis_minor
elongation / flatness / anisotropy
intensity_mean
```

`relative_position` should be expressed relative to the local tracklet reference rather than as an identity-like absolute coordinate. Absolute physical z,y,x remains separately available to candidate geometry, boundary logic and rotary positional encoding.

## Tracklet reliability stream: 12 channels

```text
log_observation_count
temporal_span_frames
association_probability_mean
association_probability_min
relative_velocity_sample_count
relative_velocity_error_ema_um
position_residual_ema_norm_um
distance_to_boundary_um
touches_boundary
log_median_volume
small_cell_indicator
crop_valid_fraction
```

These variables condition the appearance-vs-motion fusion gate. They answer questions such as “is this velocity based on two samples or eight?”, “is the image crop truncated?”, and “is morphology intrinsically unreliable because the cell is tiny?”.

## Candidate pair stream: 80 Stage-11 channels

The first 40 channels are primitive current Stage-11 evidence; the next 40 are their availability flags. See `integration/stage11.py` for the exact order.

The model intentionally does **not** use the current final `continuation_score` by default. It receives the primitive evidence and learns the weighting itself.

## Explicit model-derived motion relation: 34 channels

The network additionally constructs, in physical coordinates:

- direct A→B displacement
- global-only prediction vector generated by A
- global+relative prediction vector generated by A
- local-neighbour prediction vector generated by A
- residual vector to each prediction
- backward source residual generated from B's future
- bidirectional disagreement
- prediction-validity bits
- temporal gap representation

These 34 channels are built inside the model, so the expected positions remain first-class evidence rather than only precomputed scalar costs.

## Cell fingerprint: 96 dimensions

Recommended default crop channels:

1. normalized raw
2. target mask
3. target EDT
4. target boundary/SDF
5. surrounding-instance occupancy

The default CNN returns 96 dimensions. Optional STIR foreground/separator maps can be added by increasing `FingerprintConfig.in_channels`.

## Division pair: 16 channels

`features.build_division_pair_features` produces a daughter-order-invariant vector containing:

- combined daughter / parent volume relation
- daughter volume balance
- daughter separation
- mean/asymmetric parent-daughter distances
- daughter midpoint residual to the parent's expected future position
- branch angle/cosine
- midpoint displacement
- parent-daughter fingerprint agreement and asymmetry
- daughter-daughter fingerprint agreement
- simultaneous-start indicator
- mean temporal gap

The learned division head also receives the two already-refined edge embeddings and the independent parent division prior.
